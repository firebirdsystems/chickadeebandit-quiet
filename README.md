# Quiet Time

A [Chickadee Bandit](https://chickadeebandit.com/app-library/quiet-time) app.

Family quiet time game — who can be the most silent?

## Features

- Timed quiet sessions.
- Average decibels and loud events per player.
- A leaderboard at the end.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-quiet/releases/latest/download/bundle.json
```
